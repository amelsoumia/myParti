# myParti Application

This is a simple Java/JavaFX application that simulates venue booking and related activities. It was developed as part of a second-year coursework project.


## Requirements
- Java JDK 17 or later (compiles and runs the code)
- IntelliJ IDEA (any IDE can be used but this is recommended)

## How to run
1. Clone the repository to your local machine
2. Open the project in IntelliJ IDEA (or your chosen IDE)
3. Make sure JDK 17 or later is selected
4. Once all the files are loaded, navigate to 'src/main/java/com/example/mypartiapplication' and open 'MyPartiApplication' (may also appear as com.example.mypartiapplication)
5. Run the 'MyPartiApplication' class
